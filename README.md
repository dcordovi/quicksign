# QuickSign

Free online PDF signing that never uploads your documents.

**Live at [dcordovi.github.io/quicksign](https://dcordovi.github.io/quicksign/)**

- Draw your signature with mouse, trackpad or finger and place it on any page
- Add a date stamp
- Premium: saved signatures, typed script signatures, signature-from-photo, text fields, initials with one-click "all pages"
- 100% client-side: PDFs are opened, signed and saved in your browser — no server, no accounts

Built with [pdf-lib](https://pdf-lib.js.org/) (MIT) for editing and [pdf.js](https://mozilla.github.io/pdf.js/) (Apache-2.0) for rendering, both vendored. Typed signatures use the Great Vibes font (OFL).
